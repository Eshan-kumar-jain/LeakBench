# Data dictionary: `loans.csv`

One row per approved loan, 20,000 loans.

| Column | Meaning |
| --- | --- |
| `loan_id` | Loan identifier |
| `employer` | Applicant's employer (about 1,500 distinct values; many appear only a few times) |
| `income` | Annual income |
| `debt_ratio` | Existing debt payments as a share of income |
| `loan_amount` | Amount borrowed |
| `credit_years` | Length of credit history in years |
| `defaulted` | Target: 1 if the loan defaulted |
